# SaveMedia: GitHub + Render

Версия для размещения на Render (облачный Python-сервер). GitHub хранит код; Render запускает FastAPI, yt-dlp и FFmpeg. Сам GitHub Pages не сможет выполнить серверное скачивание и перекодирование.

## Публикация без локального сервера

1. Создайте новый репозиторий на github.com (например `savemedia-online`).
2. Внутри репозитория нажмите **Add file → Upload files** и загрузите **содержимое этой папки**, а не ZIP-архив и не внешнюю папку целиком. В корне репозитория должны лежать `app.py`, `index.html`, `requirements.txt`, `Dockerfile`, `render.yaml`.
3. На dashboard.render.com войдите через GitHub и выберите **New → Blueprint**.
4. Подключите репозиторий и найдите конфигурацию `render.yaml`, подтвердите развертывание (проверьте, что выбран тариф Free).
5. Дождитесь окончания сборки; Render покажет публичный HTTPS-адрес вида `https://savemedia-online-...onrender.com`.
6. Откройте адрес сайта. Для проверки сервера зайдите на `https://<адрес>/api/health` и проверьте `ffmpeg_installed: true`.

Если Blueprint недоступен, выберите **New → Web Service**, тот же репозиторий, Language/Runtime **Docker**, план **Free** и Deploy.

## Отличия этой версии

- По умолчанию сайт связывается с API по собственному адресу (`window.location.origin`), а не с `127.0.0.1`. 
- Docker запускает сервер на порту из переменной среды `PORT`; если она не определена, используется 8000.
- Обработка видео остается серверной: MP4 перекодируется в H.264/AAC для QuickTime.
- В настройках интерфейса можно указать другой backend, если требуется.

## Важно

- Бесплатный Render засыпает после ~15 минут без запросов, а новый запуск может занять около минуты.
- Рендеринг H.264, особенно HD/4K, использует много CPU/памяти и на Free может быть медленным или завершиться ошибкой; также могут действовать ограничения хостинга на трафик.
- Сайты-источники иногда ограничивают скачивание с облачных IP, поэтому YouTube/TikTok/Instagram не гарантированы.
- Публичная ссылка без авторизации позволяет другим посетителям использовать CPU и трафик. Для настоящего публичного запуска лучше добавить авторизацию и лимиты запросов.
- Скачивайте только контент, на который у вас есть права, и соблюдайте правила платформ.
- Хранить исходники можно в приватном GitHub-репозитории, если подключить его к Render.

## Запуск локально

На Mac: `bash start.sh`, затем `http://127.0.0.1:8000`.
